# Release Notes - Universal Timer

## [v1.1.1] - 2026-11-10
### 🔧 DeskStreamCore v0.6.0으로 재빌드
- 공통 라이브러리 갱신(WiFiManager 의존 제거)에 맞춰 다시 빌드했다. 이 프로젝트는 WiFi 설정 포털을 쓰지 않으므로 **동작 변경은 없다**.
- 크기: 430,634 → 429,242 B.

## [v1.1.0] - 2026-11-09
### 🧩 공통 라이브러리 DeskStreamCore로 전환
- **복사본 제거**: `DisplayEngine.*`·`ButtonManager.*`·`BuzzerManager.*` → DeskStreamCore. 화면·버튼 순서 반전 옵션(`REVERSE_*`)은 `config.h`에 그대로 있다.
- **화면 전송**: HW I2C 1.1MHz + 페이지 병합, 고속 SW I2C(실효 약 1.15MHz), 바뀐 타일만 HW·SW 버스 **병렬** 전송 (`ds::DisplayCore`). 예전엔 바뀐 화면을 8페이지 전부 동기 전송했다.
- **버튼 수정**: 1000ms 시점에 REPEAT 이벤트가 LONG을 덮어써 BTN4 길게(리셋)가 가끔 씹히던 문제 — 이벤트를 비트마스크로 받아 둘 다 전달된다. 디바운스 30ms·300ms 후 60ms 자동 반복은 같다.
- **부저**: 비프·시작 멜로디·알람(끌 때까지 반복)을 `ds::Buzzer`로. 시작 멜로디가 비차단이 됐다. 크기 430,634 B.

## [v1.0.0] - 2026-11-04
### ✨ Initial Release (신규 프로젝트 생성)
- **4-OLED 인터랙티브 범용 카운트다운 타이머**:
  - OLED 1: 시 (00H ~ 99H) 표시 및 BTN 1 단축/연속 조절
  - OLED 2: 분 (00M ~ 59M) 표시 및 BTN 2 단축/연속 조절
  - OLED 3: 초 (00S ~ 59S) 표시 및 BTN 3 단축/연속 조절
  - OLED 4: 타이머 제어판 (START / PAUSE / RESET 및 TIME OVER 알람 점멸)
- **자동 가속 반복 입력 (Auto-Repeat)**:
  - BTN 1~3 버튼을 누르고 있으면 300ms 후 60ms 간격(초당 약 16~17회)으로 고속 연속 증가.
- **타임아웃 자동 복원 메모리**:
  - 카운트다운 시작 시 설정한 시간을 자동 백업.
  - 타임아웃 종료 후 알람이 울릴 때 임의의 버튼을 누르면 부저가 즉시 꺼지며 직전 설정 시간으로 자동 복원.
- **고속 하이브리드 I2C 렌더링**:
  - OLED 1, 2: ESP-IDF I2C 드라이버 기반 HW I2C (GPIO 5, 6)
  - OLED 3, 4: GPIO 레지스터 직접 제어(W1TS/W1TC) SW I2C (GPIO 2, 3)
  - 화면별 독립 1024B 프레임 버퍼 주입으로 U8g2 전역 정적 버퍼 간섭 원천 차단.
- **이벤트 기반 더티 체킹 (Dirty-Checking)**:
  - 변경된 단 하나의 화면만 I2C로 전송하여 평상시 I2C 지연 0ms 달성 및 즉각적인 버튼/부저 반응성 확보.
- **비차단 부저 시스템**:
  - `millis()` 상태 머신 기반으로 동작하여 30ms 단음 비프음 및 타임아웃 경보음 출력 중에도 시스템 멈춤 없음.
