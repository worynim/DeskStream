# 📡 Wireless_Analyzer: 2.4GHz 무선 환경 분석기 (v0.5.1)

ESP32-C3의 WiFi·BLE 무선부를 측정 도구로 써서 주변 2.4GHz 환경을 512x64 화면에 보여주는 단독 장치입니다.
공유기에 접속하지 않고, PC·인터넷 연결도 필요 없습니다.

## ✨ 핵심 기능

- **화면 6개**: 채널 스펙트럼 · 채널 혼잡도 · AP 목록 · AP 추적 · BLE 기기 · 요약
- **추천 채널**: 같은 채널·옆 채널 겹침과 실측 채널 활동량으로 가장 한산한 채널을 고름
- **AP 추적**: 고른 AP의 신호 세기를 빠르게 갱신하고 부저로 안내 (공유기 위치 찾기)
- **BLE 기기 수**: 거리 구간별 수와 이름·제조사 — 기기 주소는 표시·전송하지 않음
- 모드 · 밝기 · 뒤집기는 저장돼 다시 켜도 유지

## 🎮 버튼

| 버튼 | 짧게 | 길게 |
|:--|:--|:--|
| BTN1 | 이전 모드 | 화면 180° 뒤집기 |
| BTN2 | 다음 모드 | 스캔 일시정지/재개 |
| BTN3 | 목록·추적: 이전(더 센) AP | 추적: 부저 켜기/끄기 |
| BTN4 | 목록·추적: 다음(더 약한) AP | 밝기 단계 |

## 🚀 설치

[웹 플래셔](https://worynim.github.io/DeskStream/)에서 "무선 환경 분석기"를 골라 설치합니다.
직접 빌드할 때는 `Partition Scheme`을 **Huge APP**로 고르고, DeskStreamCore · U8g2 · NimBLE-Arduino가 필요합니다.
