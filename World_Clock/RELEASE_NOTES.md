# Release Notes - World_Clock

## [0.1.0] - 2026-11-15
### 🌍 첫 배포본 — 세계 4곳 시계
- OLED 화면 하나에 도시 하나의 현지 시각. 큰 `AM`/`PM`(AM = 위, PM = 아래), 해/달 아이콘, 0~24시 하루 막대로 오전/오후와 낮/밤을 구분한다.
  1번 화면이 기준 도시이고 다른 화면은 날짜가 다르면 `+1일`/`-1일`을 표시한다.
- **화면을 눌러 장소 설정** (화면 = 버튼): 화면을 길게 누르면 그 화면이 미리보기가 되고 나머지 세 화면이 왼쪽부터
  세계 지도(취소) · 서쪽 · 동쪽 버튼이 된다. 짧게 = 도시 하나, 누르고 있기 = 시간대 단위로 건너뛰기. 20초 입력이 없으면 취소.
- 시계 화면 짧게 누르기: 화면 1 = 12/24시, 화면 2 = 밝기 4단계, 화면 3 = 정보 카드, 화면 4 = 한글/영문.
- 도시 113개(한글·영문 이름), 서머타임 자동 반영. NTP 로 UTC 만 받고 현지 시각은 `tz_calc` 가 계산한다 (시스템 TZ 는 `UTC0` 고정).
- 시간대 규칙은 tzdata 2026f 기준. 호스트 테스트가 도시마다 2026-12 ~ 2029-11 의 UTC 차이를 시스템 zoneinfo 와 대조한다 (183만 표본 일치).
  이 대조로 밴쿠버·캘거리가 2026-11 부터 서머타임 없는 고정 시간대인 것을 반영했다.
- 도시 4곳 · 12/24시 · 밝기 · 표시 언어를 NVS 에 저장 (`ds::ConfigStore`, 네임스페이스 `worldclock`, 도시는 목록 순서가 아닌 고정 ID).
- WiFi 정보는 DeskStreamCore 내장 접속 포털(`World_Clock_Setup`). 웹 서버는 띄우지 않는다.
- 렌더러를 U8g2 C API 로 작성해 PC 에서 같은 코드로 화면 이미지를 뽑는다 (`test/render/run.sh`).
- 크기 약 1.26MB (Huge APP 39%). 웹 플래셔 배포본 추가 (`firmware/projects.json` order 15).
- **확인 범위**: PC 화면 미리보기, 호스트 테스트, 빌드. **실제 보드에서는 아직 확인하지 않았다** (글자 크기, 누르기 감각, WiFi 포털, NTP).
