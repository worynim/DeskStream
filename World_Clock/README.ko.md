# 🌍 World_Clock: 세계 4곳 시계 (v0.1.0)

DeskStream 보드의 OLED 4개에 **지구 위 4곳의 현재 시각**을 하나씩 보여주는 시계입니다.
장소는 웹 페이지 없이 **화면을 눌러서** 고릅니다 (이 보드는 OLED 화면을 누르면 그 화면의 버튼이 눌립니다).

https://youtu.be/2hlVDkWg71k

> **0.1.0은 PC 화면 미리보기·호스트 테스트·빌드까지만 확인한 첫 배포본입니다. 실제 보드 동작 확인은 아직입니다.**

## ✨ 핵심 기능

- **화면 하나 = 도시 하나**: 큰 AM/PM, 해/달 아이콘, 0~24시 하루 막대로 오전/오후와 낮/밤 구분
- 1번 화면이 기준 도시 — 날짜가 다르면 `+1일` / `-1일` 표시
- **도시 113개**(한글·영문), 30·45분 단위 시간대와 서머타임 자동 반영
- 12/24시 · 밝기 · 한글/영문 전환, 설정은 저장돼 다시 켜도 유지

## 🎮 누르기 (시계 화면)

| 화면 | 짧게 | 길게 |
|:--|:--|:--|
| 화면 1 | 12시 ↔ 24시 표기 | 이 화면의 장소 설정 |
| 화면 2 | 밝기 4단계 | 이 화면의 장소 설정 |
| 화면 3 | 정보 카드 3초 (날짜 · UTC 차이 · 시차) | 이 화면의 장소 설정 |
| 화면 4 | 한글 ↔ 영문 | 이 화면의 장소 설정 |

장소 설정에서는 나머지 세 화면이 **지도(취소) · ◀ 서쪽 · 동쪽 ▶** 버튼이 되고, 고치는 화면을 짧게 누르면 저장합니다.

## 🚀 설치

1. [웹 플래셔](https://worynim.github.io/DeskStream/)에서 "세계 시계"를 골라 설치합니다. 직접 빌드할 때는 `Partition Scheme`을 **Huge APP**로 고릅니다.
2. 저장된 WiFi가 없으면 휴대폰으로 `World_Clock_Setup`에 접속해 `192.168.4.1`에서 WiFi를 설정합니다 (다른 DeskStream 프로젝트와 공유).
