# World_Clock — 세계 4곳 시계 구현 계획

> 상태: **P1~P4 구현, 빌드·호스트 테스트 통과 — 실제 보드 확인 전 (펌웨어 0.1.0)** · 작성일 2026-11-15
> 목표: DeskStream 보드의 OLED 4개에 **지구 위 4곳의 현재 시각**을 하나씩 보여준다.
> 장소는 웹 페이지 없이 **화면을 눌러서** 고르고 (이 보드는 OLED 화면을 누르면 그 화면의 버튼이 눌린다), 각 화면은 그곳이 **오전인지 오후인지 한눈에** 알 수 있게 그린다.
> 폴더·프로젝트 이름 `World_Clock`은 가칭이다.

## 1. 하드웨어로 할 수 있는 것 / 제약

보드는 그대로 쓴다 ([hardware.md](../hardware.md)). 추가 부품 없음.

| 자원 | 이 프로젝트에서의 쓰임 | 제약 |
|:--|:--|:--|
| OLED 128x64 × 4 | 화면 하나 = 장소 하나 | 단색. 색으로 낮/밤을 구분할 수 없어 **모양·위치·반전**으로 구분해야 한다 |
| 버튼 4개 | **화면 i를 누르면 BTN i가 눌린다** (화면 = 버튼). 장소 고르기, 12/24시 표기, 밝기 | 화면당 버튼 하나뿐 → 화면에 그 버튼의 기능을 직접 그려 준다 (§3) |
| ESP32-C3 WiFi | NTP로 UTC 시각 받기 | **RTC·배터리 없음** → 전원을 넣을 때마다 WiFi로 시각을 받는다. SSID·비밀번호는 `ds::WifiService` 내장 접속 포털로 넣는다 (도시 선택용 웹 페이지는 만들지 않는다) |
| 부저 | 버튼음, (선택) 정시 알림 | — |
| 플래시 4MB | 도시 표·세계 지도 비트맵·한글 글꼴 | 갈무리7 한글 글꼴 166KB → 공통 `partitions.csv` + Huge APP 필요할 수 있음 |

시각 계산은 **UTC 하나만 NTP로 받고**, 장소별 현지 시각은 도시 표에 든 시간대 규칙(서머타임 포함)으로 장치 안에서 계산한다.
장소를 바꿔도 네트워크를 다시 쓰지 않으므로 미리보기가 즉시 바뀐다.

## 2. 시계 화면 디자인 (128x64 한 장) — 오전/오후 구분

`AM`/`PM`을 **큰 영문 글자**로 쓰고, 낮/밤은 **해·달 아이콘**으로 따로 보여준다.

```
┌────────────────────────────────┐
│ 뉴욕  ☀            11/14 토 -1일 │  ← 도시 이름(한글) · 낮/밤 아이콘 · 현지 날짜·요일 · 날짜 차이
│                                │
│  █▀█ █▄█    ██  ██   ██  ██     │  ← AM/PM: 높이 약 16~18px 굵은 영문 (큰 숫자의 절반 이상)
│  █▀█ █ █    ██  ██ : ██  ██     │     AM은 숫자 줄의 위쪽, PM은 아래쪽에 놓아 위치로도 구분
│             ██  ██   ██  ██     │
│                                │
│▓▓▓▓▓▓░░░░░░░▲░░░░░░░░░░▓▓▓▓▓▓▓▓│  ← 하루 막대(0~24시, 얇게 5px): 밤은 채움, 낮은 비움, ▲ = 지금
└────────────────────────────────┘
```

| # | 장치 | 무엇을 알려주나 | 비고 |
|:--|:--|:--|:--|
| ① | **큰 `AM` / `PM` 글자** (숫자 왼쪽) | 오전/오후 | 영문. AM = 위쪽, PM = 아래쪽 자리. 24시 표기에서도 그대로 둔다 |
| ② | **해/달 아이콘** (도시 이름 옆, 약 12x12) | 낮(06~18시) = 해, 밤 = 달 | 고정 시각 기준. 위도·계절별 실제 일출/일몰 계산은 범위 밖 |
| ③ | **하루 막대** (맨 아래, 얇게) | 하루 중 어디쯤인지 | 낮 구간(6~18시)을 채우고 지금 시각에 세로 표시. 4화면을 나란히 보면 표시 위치만으로 시차가 보인다 |

- **P0 결과 (PC 미리보기)**: AM/PM = `fub17`(굵은 대문자 17px), 숫자 = `logisoso28`(폭이 좁은 28px).
  `PM` + `12:00`(가장 넓은 경우)이 겹치지 않고 들어간다. `fub25`·`logisoso30` 숫자는 네 자리 시각에서 AM/PM과 겹쳤다.
  낮/밤 아이콘은 AM/PM이 비운 자리(AM이면 아래, PM이면 위)에 둔다. 하루 막대는 낮 구간을 채우고(밝음 = 낮) 밤은 테두리만 그린다.
- 초는 표시하지 않고 `:`만 1초마다 깜빡인다 (바뀐 타일만 전송되는 `display.push()`와 잘 맞는다).
- 날짜 차이: **기준 도시(1번 화면)** 와 날짜가 다르면 `+1일` / `-1일` 표시.
- 도시 이름·요일은 한글(갈무리7), 오전/오후만 영문이다.

## 3. 장소 고르기 — 버튼만으로 쉽게

### 3.1 원칙

1. **고르는 것은 도시 이름이다.** UTC 오프셋이나 TZ 문자열을 직접 넣게 하지 않는다 (서머타임까지 표가 처리).
2. **방향이 지리와 같다.** ◀ = 서쪽, ▶ = 동쪽. 목록은 경도 순서(서→동)로 한 줄이고 양 끝이 이어진다(지구 한 바퀴).
3. **미리보기가 즉시 바뀐다.** 넘기는 동안 그 화면에 그 도시의 현재 시각이 바로 나온다 — 확인 단계가 따로 없다.
4. **두 가지 속도.** 짧게 = 도시 하나, 누르고 있기 = 시간대 단위로 건너뛰기. 도시 약 100개(시간대 약 38개)를
   끝에서 끝까지 누르고 있으면 약 3초.
5. **잘못 눌러도 안전.** 저장 전에는 취소할 수 있고, 20초 동안 입력이 없으면 저장 없이 시계로 돌아간다.

### 3.2 설정 화면 — 화면이 곧 버튼

**고치고 싶은 화면을 길게 누르면** 그 화면의 장소 설정이 시작된다. 고치는 화면은 제자리에서 테두리가 깜빡이며
미리보기를 보여주고, 나머지 세 화면은 **자기 기능을 화면에 크게 그린 버튼**이 된다 (누르는 곳에 설명이 있으므로 외울 것이 없다).

나머지 세 화면은 "고치는 화면을 뺀 나머지를 왼쪽부터" **지도·취소 → ◀ 서쪽 → 동쪽 ▶** 순으로 배정한다 (`setupRole()`).
지도가 항상 가장 왼쪽이고, 서쪽 버튼이 동쪽 버튼보다 항상 왼쪽에 있다.

| 고치는 화면 | 화면 1 | 화면 2 | 화면 3 | 화면 4 |
|:--|:--|:--|:--|:--|
| 1 | **미리보기** | 지도·취소 | ◀ 서쪽 | 동쪽 ▶ |
| 2 | 지도·취소 | **미리보기** | ◀ 서쪽 | 동쪽 ▶ |
| 3 | 지도·취소 | ◀ 서쪽 | **미리보기** | 동쪽 ▶ |
| 4 | 지도·취소 | ◀ 서쪽 | 동쪽 ▶ | **미리보기** |

- **미리보기**: 도시 이름 · 낮/밤 아이콘 · 현재 시각 · UTC 차이 · 기준 도시와의 시차 · `누르면 저장`.
- **서쪽/동쪽 화면**: 큰 화살표와 함께 누르면 갈 도시 이름·UTC 차이를 미리 보여준다.
- **지도 화면**: 128x64는 정확히 2:1이라 등장방형 세계 지도 한 장이 딱 맞는다(1KB 비트맵).
  고른 도시 위치에 점이 깜빡이고 그 경도에 세로선을 그린다. 구석에 `취소` 표시.
- 다른 화면도 고치려면 저장한 뒤 그 화면을 길게 누른다.

### 3.3 누르기 동작

| 상태 | 화면(버튼) | 짧게 | 길게 / 누르고 있기 |
|:--|:--|:--|:--|
| 시계 | 화면 1 | 12시 ↔ 24시 표기 | **이 화면 장소 설정** |
| 시계 | 화면 2 | 밝기 단계 (4단계) | **이 화면 장소 설정** |
| 시계 | 화면 3 | 정보 카드 3초 (4화면 모두 연도 포함 날짜·UTC 차이·기준 도시와의 시차) | **이 화면 장소 설정** |
| 시계 | 화면 4 | **표시 언어 한글 ↔ 영문** (도시 이름·요일·설정 화면 글자. AM/PM 은 항상 영문) | **이 화면 장소 설정** |
| 설정 | 고치는 화면 | **저장하고 나가기** | — |
| 설정 | 지도 화면 | 취소(저장 안 함) | — |
| 설정 | 서쪽 화면 | ◀ 서쪽 도시 하나 | 서쪽 시간대로 계속 건너뛰기 (0.5초 뒤부터 0.15초 간격) |
| 설정 | 동쪽 화면 | ▶ 동쪽 도시 하나 | 동쪽 시간대로 계속 건너뛰기 |

- 시계 화면의 짧게 누르기는 바뀐 내용을 그 화면에 1초 띄운다 (`밝기 2/4` 등).
- 설정에 들어갈 때의 길게 누르기는 고치는 화면에서 일어나고, 그 화면은 짧게 누르기(저장)만 받으므로
  손을 떼기 전의 반복 입력이 도시를 넘기지 않는다.
- 설정 화면에서 20초 동안 입력이 없으면 저장하지 않고 시계로 돌아간다.
- 화면 180° 뒤집기는 넣지 않는다 (화면을 누르는 구조라 장착 방향이 고정이라고 보았다 — 필요하면 추가).

### 3.4 도시 표

- 113개 도시(주요 수도·대도시, 30분·45분 단위 시간대 포함 — 인도 +5:30, 네팔 +5:45 등), 한글·영문 이름.
- 항목: 고정 ID(u8) · 한글 이름 · 영문 이름 · 경도·위도(지도 좌표 계산용) · 시간대 번호.
  시간대는 `{표준시 UTC 차이, 서머타임 규칙}` 표로 따로 두어 도시들이 공유한다. 서머타임 규칙은
  "몇 월 몇 번째 무슨 요일 몇 시" 구조체다 (POSIX TZ 문자열을 파싱하지 않는다).
- NVS에는 **목록 순서가 아니라 고정 ID**를 저장한다 — 나중에 도시를 추가·재정렬해도 저장값이 다른 도시로 바뀌지 않는다.
- 규칙 기준: **tzdata 2026f**. `test/run_all.sh`가 도시마다 2026-12 ~ 2029-11 의 UTC 차이를 시스템 zoneinfo 와
  대조한다 (183만 표본 일치). 이 대조로 밴쿠버·캘거리가 2026-11 부터 서머타임 없는 고정 시간대로 바뀐 것을 반영했다.
- 한계: 서머타임 규칙은 각국 정책으로 바뀐다. 표는 펌웨어에 들어 있어 **바뀌면 펌웨어 갱신이 필요**하다.
  모로코처럼 라마단에 따라 바뀌는 곳은 넣지 않았다.

## 4. 소프트웨어 구조

[AI_GUIDE.md](../AI_GUIDE.md) 규칙대로 화면·버튼·부저·WiFi·NTP·설정 저장은 `DeskStreamCore`를 쓴다. 웹 서버는 띄우지 않는다.

```
World_Clock/
├── World_Clock.ino     # ✅ setup/loop, WiFi 포털 안내, 버튼 처리, 시계 ↔ 설정 모드 전환, NVS 설정
├── config.h            # ✅ 버전, 타임아웃, 밝기 단계 등 상수
├── lang.h              # ✅ 표시 언어 (한글/영문)
├── tz_calc.cpp/.h      # ✅ 순수 로직: UTC epoch + 시간대 규칙 → 현지 시각·서머타임 여부·UTC 차이
├── city_table.cpp/.h   # ✅ 순수 데이터/로직: 도시 표, ID↔순서 변환, 서/동 이동, 시간대 건너뛰기
├── clock_view.cpp/.h   # ✅ 시계 화면 렌더러 (§2)
├── setup_view.cpp/.h   # ✅ 설정 화면 렌더러 (§3.2): 미리보기·지도·서쪽/동쪽 버튼, 화면 역할 배정
├── misc_view.cpp/.h    # ✅ 안내문(WiFi) · 알림 딱지 · 정보 카드
├── world_map.h         # ✅ 128x64 세계 지도 비트맵 (tools/gen_world_map.py 가 생성)
├── fonts.cpp/.h        # ✅ 한글 글꼴(갈무리7) 정의 — 166KB 가 한 번만 링크되게
├── u8g2_font_galmuri7_kr.h  # 한글 글꼴 (Wireless_Analyzer·Agent_Monitor와 같은 파일)
├── tools/gen_world_map.py   # ✅ world_map.h 생성 (대륙 윤곽 다각형 → 비트맵)
├── test/run_all.sh     # ✅ tz_calc·city_table 단위 테스트 + zoneinfo 대조
├── test/render/        # ✅ 화면 미리보기: 장치와 같은 렌더러를 PC에서 돌려 PNG 로 저장 (run.sh)
└── PLAN.md · partitions.csv   (README.md · RELEASE_NOTES.md 는 P5)
```

- 렌더러는 **U8g2 C API(`u8g2_t*`)** 로 그린다 — 장치(`display.screen(i).getU8g2()`)와 PC 미리보기가 같은 코드를 쓴다.
- 앱 크기 1.26MB → 기본 파티션(1.31MB)의 95%. **`Partition Scheme = Huge APP`** (공통 `partitions.csv`)로 빌드한다 (39%).
- **현지 시각 계산을 직접 구현하는 이유**: C 라이브러리의 `setenv("TZ")`+`localtime()`은 전역 상태라 4개 시간대를
  번갈아 바꾸면 `ds::TimeSync`·로그 등 다른 코드의 시각까지 흔들린다. `tz_calc`는 시간대 규칙을 받아 계산만 하는 순수 함수로
  두고, 시스템 TZ는 `UTC0`으로 고정한다. 서머타임 전환 시각(미국·유럽·남반구)을 호스트 테스트로 검증한다.
- **설정 저장** (`ds::ConfigStore`, 네임스페이스 `worldclock`): 도시 ID × 4, 12/24시, 밝기, 표시 언어.
  전부 `U8`/`BOOL`이라 필드 테이블로 충분하다.
- **갱신**: 0.5초마다(`:` 깜빡임) 또는 입력이 있을 때 4화면을 다시 그리고 `display.push()` 가 바뀐 타일만 보낸다.
- **시각 미확정 상태**: NTP를 받기 전에는 `--:--`와 "시각 받는 중"을 보여준다 (틀린 시각을 그리지 않는다).
  이 상태에서도 장소 설정은 할 수 있다.

## 5. 단계

| 단계 | 내용 | 끝났다는 기준 |
|:--|:--|:--|
| **P0** ✅ PC 미리보기로 확인 (실제 OLED 확인 남음) | 화면 목업: 고정 시각으로 시계 화면·설정 화면을 실제 OLED에 그려 글자 크기·배치 확인 | §2 숫자·칸·막대가 128x64에 들어가고 1m 거리에서 오전/오후가 구분됨 |

## 6. 결정 사항

### 정해진 것 (2026-11-15)

- **WiFi 정보**는 `DeskStreamCore` 내장 접속 포털로 넣는다. 도시를 고르는 웹 페이지·웹 서버는 만들지 않는다.
- **화면 = 버튼**: OLED 화면을 누르면 그 화면의 버튼이 눌린다 → 화면을 길게 눌러 그 화면의 장소를 설정한다 (§3.2).
- **오전/오후**는 영문 `AM`/`PM`을 크게, **낮/밤**은 해·달 아이콘으로 표시한다 (§2).
- **1번 화면이 기준 도시**다. 다른 화면은 기준 도시와의 날짜 차이·시차를 표시한다.
- **표시 언어**: 한글로 보이는 부분(도시 이름·요일·설정 화면 글자)을 영문으로도 바꿀 수 있다 — 화면 4 짧게 누르기.
- **설정 화면 배치**: 세계 지도가 가장 왼쪽 (지도·취소 → 서쪽 → 동쪽).

### 기본안대로 구현한 것 (바꾸려면 알려주기)

1. **시계 화면의 짧게 누르기 배정** (§3.3) — 화면 1 = 12/24시, 화면 2 = 밝기, 화면 3 = 정보 카드, 화면 4 = 한글/영문.
2. **하루 막대** — 맨 아래 5px, 낮 구간을 채운다.
3. **화면 뒤집기·정시 알림(부저)** — 넣지 않았다.
4. **프로젝트 이름** — `World_Clock`.
