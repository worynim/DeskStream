# ⌨️ DS DECK (DeskStream Deck) - v1.6.1

A macro pad that works like a Bluetooth keyboard with macros on its four buttons. Each button's function is shown on the OLED above it.

https://www.youtube.com/playlist?list=PL2He47zwR3XjQv_0kjdzW76SOO_vlLyVU

## ✨ Key Features

- **Button modes**: text macros (Korean/English), key combos (including F1–F12 and arrow keys), media control, open a web browser
- **Web settings**: change button labels, modes and contents in the browser and apply them instantly
- Optimized for macOS — with Karabiner-Elements, Korean/English switching types without mistakes

## 🎮 Buttons

| Button | Short | Long |
| :--- | :--- | :--- |
| BTN 1–3 | Run the configured macro | — |
| BTN 4 | Run the configured macro | Show IP address (any button returns) |

## 🚀 Setup

1. Pick it in the [web flasher](https://worynim.github.io/DeskStream/), or build it yourself.
2. On first boot, connect to the `DS_DECK_SETUP` WiFi and set up your router.
3. Connect **`DS DECK`** in your PC/Mac Bluetooth settings.
4. Long-press BTN 4, open the IP it shows and set up your macros.
