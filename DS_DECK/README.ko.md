# ⌨️ DS DECK (DeskStream Deck) - v1.6.1

버튼 4개에 매크로를 넣어 블루투스 키보드처럼 쓰는 매크로 패드입니다. 각 버튼의 기능은 위쪽 OLED에 표시됩니다.

https://www.youtube.com/playlist?list=PL2He47zwR3XjQv_0kjdzW76SOO_vlLyVU

## ✨ 핵심 기능

- **버튼 모드**: 텍스트 매크로(한/영), 단축키 조합(F1~F12·방향키 포함), 미디어 컨트롤, 웹 브라우저 열기
- **웹 설정**: 버튼 라벨·모드·내용을 브라우저에서 바꾸고 바로 적용
- macOS 최적화 — Karabiner-Elements와 함께 쓰면 한/영 전환 오타 없이 입력

## 🎮 버튼

| 버튼 | 짧게 | 길게 |
| :--- | :--- | :--- |
| BTN 1~3 | 설정한 매크로 실행 | — |
| BTN 4 | 설정한 매크로 실행 | IP 주소 표시 (아무 버튼이나 누르면 복귀) |

## 🚀 설치

1. [웹 플래셔](https://worynim.github.io/DeskStream/)에서 고르거나 직접 빌드합니다.
2. 처음 켜면 `DS_DECK_SETUP` WiFi에 접속해 공유기를 설정합니다.
3. PC/Mac 블루투스 설정에서 **`DS DECK`**을 연결합니다.
4. BTN 4를 길게 눌러 나온 IP로 접속해 매크로를 설정합니다.

## 📖 자세히

라이브러리, 매크로 규칙(`[#CAPS#]` 한/영 전환 등), Karabiner 설정, 주의 사항은 [GUIDE.ko.md](GUIDE.ko.md)에 있습니다.
