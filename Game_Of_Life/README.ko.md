# DeskStream Game of Life 🧬 - v1.1.1

OLED 4개를 이은 512x64 화면에서 **Conway의 생명 게임**을 돌리는 단독 구동 펌웨어입니다. WiFi나 PC 없이 전원만 있으면 됩니다.

https://www.youtube.com/playlist?list=PL2He47zwR3XjQv_0kjdzW76SOO_vlLyVU

## 🎮 버튼

| 버튼 | 기능 |
| :--- | :--- |
| BTN 1 | 재생 / 일시정지 |
| BTN 2 | 한 세대 진행 (일시정지 중) |
| BTN 3 | 속도 전환 (5 → 10 → 20 fps) |
| BTN 4 | 새 무작위 패턴 |
