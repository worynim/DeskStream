# ESP32-C3 Ultra-Wide OLED (512x64) Matrix - v1.3.1

OLED 4개를 가로로 이어 하나의 **512x64 초광폭 화면**으로 쓰는 그래픽 데모·테스트입니다.

https://www.youtube.com/playlist?list=PL2He47zwR3XjQv_0kjdzW76SOO_vlLyVU

## ✨ 핵심 기능

- 512px 전체를 쓰는 선·사각형·원·삼각형 그리기와 흐르는 자막 데모
- 바뀐 부분만 전송해 30 FPS로 부드럽게 표시, 시리얼로 실시간 FPS 보고

## 🎮 버튼

| 버튼 | 짧게 |
| :--- | :--- |
| BTN 1 | 화면 180° 회전 (전송 순서도 4-3-2-1로 바뀜, 다시 켜도 유지) |

## 🚀 설치

[웹 플래셔](https://worynim.github.io/DeskStream/)에서 고르거나 직접 빌드합니다 (U8g2 · LovyanGFX · DeskStreamCore 필요).
