이 프로젝트는 Hangeul_Clock v2.6.0 의 펌웨어를 BitBang I2C 로 변환한 프로젝트이다. 

하드웨어는 OLED 1.3" 4개를 사용한다. 
1.3" OLED 는 주소 설정이 불가 하여 BitBang I2C 를 사용 4개의 OLED 를 제어한다. 
1.3" OLED 는 0.96" OLED 와 다르게 드라이버가 sh1106 이다. 

클럭핀 10번핀
데이터핀은 
OLED1 : 8 
OLED2 : 7
OLED3 : 6
OLED4 : 5

버튼핀 : 0,1,3,4 
부저는 연결 x

Hangeul_Clock v2.6.0 의 펌웨어를 BitBang I2C 로 변환한다.
처음부터 새로 만들지 말고 Hangeul_Clock v2.6.0 의 펌웨어를 복사한뒤 수정하는 방향으로 진행한다.


아래 두 라이브러리를 확인 후 프로젝트를 진행한다. 

https://github.com/bitbank2/Multi_BitBang
https://github.com/bitbank2/Multi_OLED
Multi_OLED 는 Multi_BitBang 라이브러리를 이용해서 여러개의 OLED 를 제어하는 예제이다.
