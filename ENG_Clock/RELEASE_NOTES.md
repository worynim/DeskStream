# Release Notes - ENG Clock (English Language Clock)

## [v1.0.1] ✅ 커밋완료 - 2026-10-04
### 🔍 제로베이스 코드 리뷰 반영
코드만 읽고(기존 문서·메모리 제외) 처음부터 리뷰한 결과를 조치했습니다.

### 🔧 중복 제거 (단일 진실원)
- **HW/SW push 경로**: 셰도 버퍼 diff 계산과 실제 전송이 한 함수에 섞여 있었고, HW 버스(화면 0·1)와 SW 버스(화면 2·3)가 **똑같이 도는 부분이 복제**돼 있었습니다. 계산만 하는 `diffAndForEachPage()`와 함수 포인터 콜백(`onHwPageDirty`/`onSwPageDirty`)으로 분리했습니다. 실제 전송이 경계로 빠져나가 순수 계산 부분이 테스트 가능해졌습니다.
  - 부수 효과: SW 버스는 더티 구간만 직접 전송하므로, 화면 전체를 다시 그리는 경로가 사라졌습니다.
- **제목 화면 판정**: `is_flipped`에 따라 규칙이 달라지는데 같은 식이 여러 곳에 복제돼 있었습니다. `isTitleScreenOf()` 한 곳으로 모았습니다.

### 🔧 NVS 저장 무결성
- **`saveNow()`**: 검증에 실패하면 **tz만 건너뛰고 나머지 10개 필드는 그대로** 썼습니다. 검증 실패 시 NVS에 "일부만 새 값"인 상태가 남아, 사용자는 "설정 저장 완료" 로그를 보고 재부팅하면 바뀐 값 중 일부만 반영된 상태를 만납니다. **조용한 데이터 손실**입니다.
  - 지금은 검증 실패 시 **전체 저장**을 건너뜁니다. `_isDirty`를 유지하므로 다음 `setDirty()`에서 재시도됩니다.
- **알려진 제약 (이번 릴리즈에서 고치지 않음)**: 모든 저장은 5초 지연 타이머(`setDirty()` → `xTimerReset`)로만 일어납니다. `saveNow()`를 부르는 곳은 타이머 콜백 하나뿐이며, 주기적 저장도 없습니다. 모드를 바꾼 뒤 5초가 지나기 전에 전원을 끄면 그 변경은 유실됩니다. 또한 5초 안에 다른 설정을 또 바꾸면 타이머가 재시작되어 저장 시점이 뒤로 밀립니다.
  - 전원 차단 직전 경로(공장 초기화 등)에서 `saveNow()`를 명시적으로 부르는 방어가 안전합니다. `ESP.restart()` 앞에 넣으면 지연 시간과 무관하게 확정 기록됩니다.

### 🔧 입력 검증 (보안)
- **`setFontName()`**: 이 값은 (1) JSON 응답에 붙고 (2) `/fN/name.txt`의 **파일명**으로도 쓰입니다. 출구 이스케이프만으로는 경로 조작이 막히지 않으므로 **입력에서** 길이·문자를 검증합니다(`"` `\` `/` 제어문자 거부). 검증은 `setFontName()` 한 곳에 모아, 나중에 다른 경로로 들어온 값도 통과하지 않게 했습니다.
- **`jsonEscape()`**: `web_manager.cpp`에 이스케이프 함수가 없어 폰트명에 포함된 특수문자가 JSON을 깨뜨렸습니다. 슬롯명 목록에도 적용합니다.
- **`setDateOrder()`**: enum 범위 밖 값을 무시합니다.

## [v1.0.0] — 2026-10-02
### Major Update (신규 프로젝트)
- `Hangeul_Clock` v2.6.0의 기능·품질을 유지하면서 텍스트만 영어로 교체한 영어 단어 시계.
- **2-Line Word Layout**: 영어 최장 단어 `SEVENTEEN`(9자)을 수용하기 위해 한 화면 4자 제한을 깨는 어절 단위 줄바꿈을 도입.
- **POS TZ 시간대 시스템**: 고정 오프셋을 POSIX TZ 문자열(`KST-9` 등)로 교체하여 DST 자동 처리. 웹 UI에서 12개 지역 프리셋 + Custom 입력, NVS 영속 저장, 화이트리스트 입력 검증(`tz_util`).
- **Font Studio (잉크 중앙 정렬 래스터라이저)**: 브라우저에서 TTF를 38개 영문 낱자의 비트맵으로 변환해 기기에 업로드 (폰트 슬롯 5개, LittleFS).
- **호스트 테스트 인프라**: Arduino 의존 없는 순수 C++ 모듈 분리(`english_time_core`, `tz_util`, `layout_engine`, `renderer_geometry`) + 웹 JS ↔ 펌웨어 C++ 교차 검증.
