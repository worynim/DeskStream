# 📖 DeskStream Page Turner (BLE 페이지 터너) - v1.1.0

DeskStream 보드를 세로로 손에 쥐고 엄지로 버튼을 눌러 **웹소설·웹툰·유튜브 쇼츠를 넘기는** 블루투스 리모컨입니다.
스마트폰 카메라 셔터(딜레이 셔터 포함)와 PC 발표 슬라이드 넘김에도 씁니다. 별도 앱 없이 블루투스 페어링만 하면 됩니다.

## ✨ 핵심 기능

- **앱별 모드 7개**: YouTube · 카카오 웹툰/소설 · 시리즈 웹툰/소설 · 카메라 · PPT (Android에서 확인)
- **연결 기기 슬롯 3개**: 폰·태블릿·PC를 기억해 두고 버튼 두 번으로 전환
- **버튼만으로 설정**: 휠 칸 수·방향키 횟수·간격·딜레이 셔터 시간·버튼음, 전원을 꺼도 유지
- 어두운 곳에서 눈부시지 않게 테두리만 그리는 화면, 1분 화면 끄기 · 5분 딥슬립

## 🎮 버튼

장치를 세로로 쥐면 위에서부터 BTN1 ~ BTN4입니다.

| 버튼 | 짧게 | 길게 |
|---|---|---|
| **BTN1** | 이전 페이지 / 위로 스크롤 / 셔터 | — |
| **BTN2** | 다음 페이지 / 아래로 스크롤 / 딜레이 셔터 | — |
| **BTN3** | 다음 모드 | 기기(슬롯) 선택 |
| **BTN4** | 설정 메뉴 | — |

딥슬립에서는 **BTN1 또는 BTN2**로 깨웁니다.

## 🚀 설치

1. [웹 플래셔](https://worynim.github.io/DeskStream/)에서 고르거나 직접 빌드합니다.
2. 보드를 켜고 폰의 블루투스 설정에서 **`DS Page Turner`** 를 페어링합니다.
3. BTN3으로 쓰려는 앱의 모드를 고릅니다. 카카오·시리즈 소설은 앱에서 **볼륨 키로 페이지 넘기기**를 켜야 합니다.
