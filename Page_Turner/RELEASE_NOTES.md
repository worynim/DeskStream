# Release Notes - Page Turner

## [v1.1.0] - 2026-11-20
### 🌙 어두운 곳용 화면 — 밝기 최저 · 테두리로만 그리기
- **밝기**: OLED 밝기(SSD1306 contrast)를 1(0~255 중 최저)로 고정했다 (`config.h` `kBrightness`). 어두운 곳에서 눈부시지 않고 전력도 덜 쓴다.
- **테두리만**: 화살표·카메라·타이머·−/+·▶ 아이콘과 맨 아래 이름표(`BTN1`, `MODE 4/7` …)를 채움/반전 없이 테두리로 그린다. 켜지는 픽셀이 줄어 OLED 전력이 준다.
- **선택 표시**: 두 값 항목(Beep·Cursor)과 기기 선택 화면에서 고른 쪽은 반전 대신 테두리를 두 겹으로, 쓰는 중인 슬롯은 번호에 테두리를 두른다. 값 위치 막대만 위치를 알아보도록 채운 채로 둔다.
- **Change mode 두 줄**: OLED3 맨 위 설명이 64px 폭에서 끝 글자 `e`가 잘려 `Change` / `mode` 두 줄로 나눴다.
- 크기: 740,919 B.

## [v1.0.0] - 2026-11-20
### 🎉 정식판 — 설정 저장 · 연결 기기 슬롯 3개 · 화면 끄기/딥슬립 · 웹 플래셔 등록
- **구조**: 시험판 한 파일을 모듈로 나눴다. 모드 표·설정 메뉴·딜레이 셔터·절전 판단·슬롯 표는 하드웨어와 분리해 호스트(g++) 테스트(`test/run_all.sh`)로 검증한다.
- **설정 저장**: 모드별 설정·Beep·마지막 모드를 NVS(`pturner`)에 값 목록의 위치로 저장한다. 목록 밖 값은 기본값으로 돌린다.
- **막히지 않는 전송**: 신호는 별도 태스크가 보낸다. 긴 휠 전송(최대 30칸 × 250ms) 중에도 버튼·화면이 반응하고, 전송 중 BTN1/BTN2는 버린다(손을 뗀 뒤 더 넘어가지 않게).
- **연결 기기 슬롯 1~3** (BTN3 길게): BTN1~3으로 슬롯 고르기 → 같은 버튼 한 번 더 = 사용, 길게 = 새 기기 페어링 대기, BTN4 = 취소. 쓰는 슬롯 기기만 화이트리스트로 받아 다른 기기에는 보이지 않는다. 기존 기기는 새 기기가 본딩되는 순간 교체하고, BTN3·60초 경과 시 쓰던 기기로 돌아간다. 이미 페어링된 기기는 빈 슬롯에 자동 배정(`pt_slots`).
- **화면 끄기·딥슬립**: 1분 무입력 → 화면 끄기(첫 버튼은 화면만 켬), 5분 → 딥슬립(BTN1·BTN2로 깨움, 깨운 누름은 신호로 보내지 않음, 누른 채면 놓을 때까지 대기).
- **화면**: 버튼 이름표(`BTN1`, `MODE 4/7`, `BT1 ON`)를 맨 아래, 버튼이 하는 일 설명을 맨 위로. 시작·페어링 대기·기기 선택·Sleep 화면 추가. 기기 선택에서 쓰는 슬롯은 번호 칸을 반전.
- **버그 수정 (실기에서 발견)**
  - 연결이 끊긴 뒤 광고가 다시 시작되지 않아 다른 기기·이전 기기 모두 장치를 찾지 못함 → `advertiseOnDisconnect(true)` (NimBLE 2.x 기본값은 꺼짐).
  - 두 번째 기기를 페어링하면 첫 기기 페어링이 지워짐 → NimBLE 구독(CCCD) 저장 한도 8개가 HID 기기 2대(대당 4~5개)에서 넘쳐 가장 오래된 기기를 지웠다. `build_opt.h`로 24개.
- 블루투스 이름 `DS Page Turner` (시험판 `DS Turner Test`에서 바뀜 — 폰에서 등록 해제 후 다시 페어링).
- 공통 파티션(`partitions.csv`, Huge APP). 크기: 742,621 B.

## [v0.1.0] - 2026-11-20
### ✨ 시험판 — 앱별 입력 방식 확인용 BLE 페이지 터너 (신규 프로젝트)
- **복합 BLE HID**: 키보드(ID 1) · Consumer 미디어 키(ID 2) · 마우스(ID 3, 휠과 커서 이동) 리포트를 한 장치로 묶었다. NimBLE-Arduino 2.5.0 사용. 본딩·Just Works·SC, 블루투스 이름 `DS Turner Test`.
- **앱 이름별 모드 7개**: YouTube(휠 x3·30ms·커서 숨김), Kakao Webtoon(방향키 x4·30ms), Kakao Novel(볼륨), Series Webtoon(휠 x10·80ms·커서 숨김), Series Novel(볼륨), Camera(BTN1 볼륨+ 셔터, BTN2 딜레이 셔터 — Timer 2/3/5/10s, 기본 3s), PPT(PageUp/PageDown). 기본값은 Android 실기 시험 결과다 (PPT는 실기 미확인).
- **휠은 1칸씩 간격을 두고** 보낸다. 한 번에 여러 칸을 보내면 화면이 확 넘어갔다.
- **버튼**: BTN1 이전·위, BTN2 다음·아래, BTN3 모드, BTN4 설정 메뉴(BTN1/2 값 선택 · BTN4 다음 항목·저장 · BTN3 취소). 공통 설정 Beep(버튼음 On/Off).
- **세로 화면**: `U8G2_R1`로 90° 돌려 세로로 쥐었을 때 OLED1이 위. 각 OLED는 반전 머리줄 + 화살표·아이콘 + 아래 설명으로 옆 버튼의 역할을 보여준다. OLED4는 보내는 신호 종류(Wheel/Arrow/Volume/PgUp/Dn)와 설정 요약을 보여준다. 설정 메뉴는 항목 설명, 큰 −/+, 값 위치 막대, X(취소)·▶/✓(다음·저장)를 그린다. 두 값 항목(Beep·Cursor)은 −/+ 대신 BTN1 = Off/Show, BTN2 = On/Hide 선택 상자로 보여주고 고른 쪽을 반전한다.
- **딜레이 셔터**: Camera 모드 BTN2를 누르면 Timer 초를 OLED2에 크게 세며 1초마다 비프하고, 끝나면 볼륨+로 셔터를 누른다. 세는 중에 BTN2를 다시 누르거나 모드·설정으로 가면 취소된다.
- 시험 과정에서 뺀 것: HID Camera Control 페이지 초점 키(0x90/0x20, Android 실기에서 반응 없음), 터치스크린 흉내(탭·스와이프, Android에서 거의 동작 안 함), 마우스 드래그(커서가 화면 끝에 닿으면 반대로 넘어가는 등 불안정).
- **제한**: 설정값은 저장하지 않아 전원을 끄면 기본값으로 돌아간다. 웹 플래셔 미등록. 정식 버전 설계는 `DESIGN.md`.
- 크기: 720,279 B (기본 파티션).
